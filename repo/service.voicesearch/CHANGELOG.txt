Kodi Voice Search - Changelog
==============================

1.5.2
-----
- Fixed the icon not showing in the repository browsing screen.

1.5.1
-----
- Fixed a misplaced comment in kodi_voice_watcher_google.py (no
  functional change). Reviewed in full and confirmed otherwise
  identical to 1.4.11.

1.5.0
-----
- Listens for Kodi's on-screen keyboard and fills it using Google
  speech recognition.
- Installs Python and required packages automatically on first run,
  into an isolated environment that never touches any existing
  Python install.
- Kodi web server username and password are configured via this
  addon's own Settings screen.
- Help tab in Settings explains setup and requirements in full.
- Notifies you to restart Kodi after an update or a settings change.
- Windows only.

Versioning note: any change to service.py, setup.py,
kodi_voice_watcher_google.py, or setup_kodi_voice_search.bat should
bump the version number here and in addon.xml.
